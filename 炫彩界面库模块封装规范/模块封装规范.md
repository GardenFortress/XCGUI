# XCGUI 模块封装规范

> **本文件用途**: 后续 AI 协作或人工开发新模块时, **只需读完本文** 即可直接动手, 不必再回头分析
> 现有 `module_xcgui_*.h/.cpp` 与 IDE 文档 (<https://www.xcgui.com/doc-ui/index.html>,
> <https://jmp6bo524n.k.topthink.com/@xcdoc/IDE-jichengkaifahuanjing.html>).
> 所有结论已经从工作区现有四个生产级模块 (`editdw` / `video` / `image` / `blur`) 反向提炼,
> 配套 `.cursor/rules/*.mdc` 项目硬约束.

------------------------------------------------------------------------------
## 0. 文件位置与命名

| 项 | 约定 |
|---|---|
| 模块文件位置 | `xcgui/炫彩界面库/module_xcgui_<功能>.h` + `module_xcgui_<功能>.cpp` |
| 类文件命名 | 类名 = `CX<功能>` (大驼峰, 例 `CXBlur` / `CXVideo` / `CXImageEx` / `CXEditDW`) |
| 头文件 include guard | `#ifndef XCGUI_<功能>_H` / `#define XCGUI_<功能>_H` (全大写) |
| 内部辅助 struct | `_X<功能>_<名>` (例 `_XEditDW_Para` / `_XImage_Frame` / `_XVideo_PacketNode`) |
| 公开 enum | `x<功能>_<动作>_` (例 `xvideo_state_` / `ximage_fit_mode_` / `xblur_theme_`) |
| 公开 typedef 回调 | `X<功能大写>_PROC_<动作>` (例 `XVIDEO_PROC_OPENED` / `XIMAGE_PROC_LOADED`) |
| 配套测试 | `test_<功能>_main.cpp` + `build_test_<功能>.ps1` |
| 配套文档 | 必填 `README.md` 顶层表 + 可选 `CX<功能>_README.md` 详细说明 |
| 资源拷贝目标 | `xcgui/炫彩界面库/<功能>资源子目录/` (例 `ffmpeg/` 已被 video/image 共用) |

## 1. 头文件骨架 (照抄即可)

下方 *骨架完整保留所有 `@` 标签*, 替换 `<...>` 占位即可生成新模块头. **顺序不能乱** ——
@模块名称 / @依赖 / 真实 #include 链 / @src / @lib / @隐藏 / 公开类型 / @分组 / 类声明.

```cpp
#ifndef  XCGUI_<功能大写>_H
#define  XCGUI_<功能大写>_H
//@模块名称  炫彩界面库-<中文功能名>
//@版本  1.0.0
//@日期  2026-MM-DD
//@作者  <作者名>
//@QQ    <QQ号>
//@依赖  module_xcgui_class.h
//@模块备注  <一段长备注: 设计思路, 路线选择, 关键权衡, 兼容性>.
//          <可多行, 用 // 加 4~10 空格缩进续接>.
//@模块信息结束

// =================================================================
// 头文件依赖拓扑顺序说明 (照抄, 不要改顺序):
//   - @依赖 是 IDE 解析器(智能感知 / 别名 / 语法着色) 用的, *不会* 自动注入
//     #include 给 cl.exe; 所以下面要再用真实 #include 链一次.
//   - d2d1.h 必须先于 module_xcgui.h 完成, 让 d2d1 引入的 POINTF 抢占名字
//     (xcgui 内部用 __IOleControlSite_INTERFACE_DEFINED__ 保护宏跳过重复定义).
//   - module_base.h / module_xcgui.h / module_xcgui_class.h 自身只用 @依赖
//     声明上游, 不带 #include 链, 这里必须按拓扑顺序逐个手动 #include.
// =================================================================

// (A) 可选: 资源拷贝指令 (IDE 编译时把 dll/lib 拷贝到输出目录)
//@复制文件 @当前模块路径 "<相对路径>\\<dll 文件名>"

// (B) D2D / 系统 / 第三方 头. 必须先于 module_xcgui.h.
#include <d2d1.h>
#include <gdiplus.h>            // 仅当 GDI+ 路径用到
// extern "C" 只裹纯 C 库 (FFmpeg / OpenSSL 等). C++ 库 (DirectWrite / D2D) 不裹.
extern "C" {
// #include <libavformat/avformat.h>   // 例: FFmpeg
}

// (C) 标准库
#include <atomic>
#include <mutex>
#include <vector>
#include <string>
// ...

// (D) XCGUI 自身按拓扑顺序
#include "module_base.h"
#include "module_xcgui.h"
#include "module_xcgui_class.h"

//@src "module_xcgui_<功能>.cpp"

// (E) 链接 lib (双写: @lib 给 IDE, #pragma comment 给 cl.exe)
//@lib "<lib 文件相对路径>.lib"
#pragma comment(lib, "<lib 文件名>.lib")
#pragma comment(lib, "User32.lib")
#pragma comment(lib, "Gdi32.lib")
// ... (不要忘加运行时真用到的所有系统 lib)

//@隐藏{
// 类外内部 struct: 放这里. 隐藏块内的符号 IDE 不展示给炫语言端.
// (类内嵌 struct + std::deque<内嵌类型> 在某些预编译头解析器下顺序异常,
//  统一外置.)
class CX<功能>;     // 前置声明给下面 typedef 用.
struct _X<功能>_<内部条目>{
    // ...
};
//@隐藏}

///<公开 enum 描述 (放在 enum *上方* 1 行, 用三斜杠 ///, IDE 智能感知会读取作 tooltip)
//@别名 <中文枚举类型名>
enum x<功能>_<动作>_
{
    //@别名 <中文枚举值名>
    x<功能>_<动作>_<值>  = 0,    ///<行尾说明 (用 ///<...)
    // ...
};

///<公开 struct 描述
//@别名 <中文结构体名>
struct <功能>_<动作>_
{
    //@别名 <字段中文名>
    <类型>   <字段>;          ///<字段说明
    // ...
};

// 事件回调原型 (C 风格函数指针 + void* 用户数据). 不用 std::function:
// 炫语言 / C / 旧 C++ 端无匿名函数, 函数指针 + void* 是跨语言通用形态.
//@别名  <功能>回调_<动作中文名>
typedef void (*X<功能大写>_PROC_<动作>)(CX<功能>* p<功能>, /*...payload...*/ void* pUser);

//@分组{ <中文分组名>
//@备注  继承: CXEle, CXWidgetUI, CXObjectUI, CXBase. <一句话功能描述>.
//@别名  <中文类名>
class CX<功能> : public CXEle           // 按需选 CXEle / CXShape / CXScrollView 等
{
public:
    //@隐藏{
    CX<功能>();
    virtual ~CX<功能>();
    virtual HXCGUI GetHXCGUI() override { return m_hEle; }
    operator HELE() const { return m_hEle; }
    operator HXCGUI(){ return m_hEle; }
    virtual void operator=(const HELE hEle) override { m_hEle = hEle; }
    //@隐藏}

//@备注 <方法说明, 一行或多行均可, 多行直接续 //>
//@参数 <参数名> <说明>
//@参数 ...
//@返回 <返回值说明>
//@别名  <中文函数名()>
    HELE Create(int x, int y, int cx, int cy, HXCGUI hParent = NULL);

//@备注 <构造函数版本: 仅做转发, 同样保留中文 @备注 但不需要 @别名>
    CX<功能>(int x, int y, int cx, int cy, HXCGUI hParent = NULL){ Create(x, y, cx, cy, hParent); }

    // ===== 分节注释用 ===== (C++ 注释, 不进 IDE 别名;
    //                        建议每个语义段加一组 ===== 标题, 便于读源码.)

//@备注 ...
//@别名  <置xxx()>
    void Set<XX>(<...>);

//@备注 ...
//@别名  <取xxx()>
    <Type> Get<XX>() const;

    // 事件注册接口 (业务事件走这套, *不* 走 XEle_RegEventCPP1)
//@备注 注册"<事件名>"回调. UI 线程触发. cb=NULL 取消.
//@参数 cb 回调函数指针
//@参数 pUser 用户数据 (回调时原样回传)
//@别名  <注册事件_xxx()>
    void OnXxxEvent(X<功能大写>_PROC_<动作> cb, void* pUser = NULL);

    //@隐藏{
private:
    // ===== 私有数据 =====
    HELE  m_hEle      = NULL;
    float m_dpiScale  = 1.0f;
    // ... 其他私有成员

public:
    // 内部 XCGUI 事件转发 (公开仅给 C 风格事件回调挂接, 用户代码勿调).
    int  OnPaintImpl   (HELE hEle, HDRAW hDraw, BOOL* pbHandled);
    int  OnSizeImpl    (HELE hEle, int nFlags, UINT nAdjustNo, BOOL* pbHandled);
    int  OnTimerImpl   (HELE hEle, UINT nTimerId, BOOL* pbHandled);
    int  OnDestroyImpl (HELE hEle, BOOL* pbHandled);

private:
    // 内部辅助
    void InstallEvents();
    void OnPaintD2D(ID2D1RenderTarget* rt, HDRAW hDraw);
    void OnPaintGdi(HDC hdc, HDRAW hDraw);
    void RefreshDpiScale();
    void RebuildBkInfo();
    void RedrawSelf();
    //@隐藏}
};
//@分组}

#endif // XCGUI_<功能大写>_H
```

**所有 `//@xxx` 标签必须紧贴目标符号 (上方 0 行空行)**. 一旦中间插了空行, IDE 解析器有时会丢失关联.

## 2. `@` 标签速查表 (从现有模块反向提炼)

> 按"放置位置"分组, 不是按字母. 这样新模块直接对照写就不会漏。

### 2.1 文件级 (头部 1 块)

| 标签 | 取值 | 作用 |
|---|---|---|
| `//@模块名称` | `炫彩界面库-<中文名>` | IDE 模块树展示名 |
| `//@版本` | `<主.次.补丁>` | 模块版本号, 升级时 bump |
| `//@日期` | `YYYY-MM-DD` | 最后改动日期 |
| `//@作者` | `<署名>` | 作者署名 (可同行附 QQ) |
| `//@QQ` | `<QQ号>` | 单独行的 QQ 号. 与 @作者 同行二选一 |
| `//@依赖` | `module_xcgui_class.h` (或更上游) | **告诉 IDE 上游模块**, 不影响 cl.exe 实际编译. **必须再用 #include 真实链一次** |
| `//@模块备注` | 多行说明 | IDE 模块详情页显示 |
| `//@模块信息结束` | 无值 | 模块信息块的结束标记, **必须** |

### 2.2 文件级 (头部之外)

| 标签 | 用法 | 作用 |
|---|---|---|
| `//@复制文件 @当前模块路径 "<rel/path>"` | 多个并列 | 编译时把 dll/lib 等运行时文件拷到输出目录 |
| `//@src "<cpp 相对路径>"` | 1 个 | 告诉 IDE 本头文件配套的 cpp 文件 |
| `//@lib "<lib 相对路径或文件名>"` | 多个并列 | 告诉 IDE 链接哪些 lib (与 #pragma comment(lib, ...) 双写) |

### 2.3 类型 / 函数级

| 标签 | 适用对象 | 作用 |
|---|---|---|
| `//@分组{ <中文名>` / `//@分组}` | 包裹 `class` 或多个相关符号 | IDE 模块树分组 |
| `//@隐藏{` / `//@隐藏}` | 包裹任意符号 | IDE 不展示, 但 cl.exe 仍编译 |
| `//@别名` | enum / struct / class / typedef / 成员函数 | **炫语言端可调用的中文名**. **公开符号必填**. 函数末尾要保留 `()`, 例 `//@别名  创建()` |
| `//@备注` | 函数 / 类 / 字段 | IDE tooltip 主体. 多行直接续 `//` |
| `//@参数 <name> <desc>` | 仅函数 | 参数说明. 一行一个参数 |
| `//@返回 <desc>` | 仅函数 | 返回值说明 |

### 2.4 三斜杠 `///` 备注

`///` 是 Doxygen 风格. 用法:
- 在 enum / struct / 类型 *上方* 1 行写 `///<总说明>`, IDE 显示在 type tooltip
- 在 enum 值 / struct 字段 *右侧* 写 `///<字段说明>`, 行尾说明

`///` 与 `//@` 可同时存在: `///` 给 IDE 智能感知 + Doxygen, `//@别名` 给炫语言端调用.

## 3. 类层级 (在现有体系下选基类)

```
CXBase                                  (顶, 抽象)
└── CXObjectUI                          (有 SetStyle / EnableCSS / SetCssName)
    ├── CXWindow                        (HWINDOW)
    └── CXWidgetUI
        ├── CXEle                       (HELE, 普通元素)
        │   ├── CXScrollView            (滚动视图)
        │   ├── CXButton / CXEdit / ... (内置控件)
        │   ├── CXBlur     ★ 本仓自定义
        │   ├── CXVideo    ★ 本仓自定义
        │   └── CXImageEx  ★ 本仓自定义
        └── CXShape                     (HXCGUI shape)
            ├── CXShapeText / CXShapePic / CXShapeGif
            └── ...
```

### 3.1 选择规则

| 业务特征 | 推荐基类 |
|---|---|
| 任意可见元素, 自带 paint / size / mouse / kb 事件 | `CXEle` |
| 滚动视图 (内容可能超出元素客户区) | `CXScrollView` |
| 文本编辑类 / 富文本 (CXEditDW 范例) | `CXScrollView` |
| 仅作为 Shape 嵌入到 `CXShapeLayer` 等容器 | `CXShape` |
| 整窗口级抽象 (整窗口背景 / 整窗口模糊) | `CXEle` + 提供 `AttachToWnd` 方法 |
| 窗口对象本身 | `CXWindow` (一般不需要再派生) |

### 3.2 必须实现的样板

每个继承 `CXEle` (或 `CXScrollView` / `CXShape`) 的类 *必须* 有这 5 段:

```cpp
//@隐藏{
CX<功能>();                                            // 默认构造, 不做创建
virtual ~CX<功能>();                                   // 释放资源 (D2D/GDI/线程/句柄)
virtual HXCGUI GetHXCGUI() override { return m_hEle; }  // 给 CXBase::GetType 等使用
operator HELE() const { return m_hEle; }                // HELE h = pObj;  隐式转换
operator HXCGUI(){ return m_hEle; }                    // HXCGUI h = pObj;
virtual void operator=(const HELE hEle) override { m_hEle = hEle; }   // pObj = hEle 赋值
//@隐藏}
```

这套是 **设计器/IDE 反向赋值的契约** —— 设计器创建好 `HELE` 后写 `pObj = hEle;`,
派生类立刻接管.

## 3.5 DPI 与坐标转换 (新模块开发必读, 高翻车率)

> 每次新模块开发都在 DPI 上栽跟头. 本节集中列出 XCGUI 全部坐标转换 / DPI 相关 API,
> 加上从 `editdw` / `video` / `image` / `blur` / `shadow` 五个模块反复踩坑总结的规则.

### 3.5.1 两套坐标系 (混用即翻车)

XCGUI 同时存在 **逻辑像素** 和 **物理像素** 两套坐标:

| 系 | 单位 | 谁用 |
|---|---|---|
| **逻辑像素** (DIP, @96 DPI) | 与系统缩放 *无关* 的 "设计像素" | 大部分 `XEle_*` / `XWnd_*` / `XDraw_*` 用户层 API; 用户配置 (`m_corner` / `m_borderW` / `m_pad*` / `m_margin*`) |
| **物理像素** (device pixel) | 与系统缩放 *相关* 的设备像素 | Win32 原生 API (`GetWindowRect` / `WM_NCHITTEST` / `WM_GETMINMAXINFO` / `SetWindowPos`); D2D `ID2D1RenderTarget` 内部; DIB 自分配; `XEle_GetWndClientRectDPI` (**`DPI` 后缀** = 返物理) |

换算公式:

```cpp
int dpi = XWnd_GetDPI(hWnd);     // 系统 DPI: 96 / 120 / 144 / 168 / 192 ...
float dpiScale = dpi / 96.0f;    // 100% / 125% / 150% / 175% / 200%
phys = (int)(logical * dpiScale + 0.5);
logical = (int)(phys / dpiScale + 0.5);
```

### 3.5.2 API 速查表

| API | 输入 | 输出 | 何时用 |
|---|---|---|---|
| `XC_EnableDPI(BOOL)` | bool | — | **启动期 1 次**. 全局打开 DPI 感知. 不开 = 系统强制 1× 缩放 (糊渲) |
| `XC_EnableAutoDPI(BOOL)` | bool | — | 启动期, 自动派发 `WM_DPICHANGED` 给 XCGUI 元素 |
| `XWnd_GetDPI(hWnd)` | HWINDOW | int (96/120/144...) | 任何时候. **运行期 DPI 切换实时返新值**. 推荐每帧 paint / `WM_SIZE` 重读, 不要只靠 `WM_DPICHANGED` (XCGUI 有时 swallow) |
| `XWnd_PointToDPI(hWnd, &pt)` | 逻辑点 | in-place 改物理 | 拿 XCGUI 给的逻辑坐标传给 Win32 API 之前 |
| `XWnd_RectToDPI(hWnd, &rc)` | 逻辑 rect | in-place 改物理 | 同上, 矩形版 |
| `XWnd_ScreenToClient(hWnd, &pt)` | 物理屏幕 | 物理客户区 | `WM_NCHITTEST` lParam 是物理屏幕, 转客户区比对 |
| `XWnd_ClientToScreen(hWnd, &pt)` | 物理客户区 | 物理屏幕 | 反向 |
| `XEle_GetWndClientRectDPI(hEle, &rc)` | — | **物理** rect (相对窗口客户区) | **D2D 模式 paint 首选**: 与 RT 同坐标系, 不需再乘 dpiScale |
| `XEle_GetWidth/Height(hEle)` | — | **逻辑** | GDI / GDI+ paint, 需乘 dpiScale + `XDraw_GetOffset` 偏移 |
| `XEle_RectClientToWndClient(hEle, &rc)` | 元素本地逻辑 rect | 窗口客户区逻辑 rect | 子元素 → 父窗口 (逻辑) |
| `XEle_RectClientToWndClientDPI(hEle, &rc)` | 元素本地逻辑 rect | 窗口客户区**物理** rect | 同上 + 顺手乘 DPI |
| `XEle_RectWndClientToEleClient(hEle, &rc)` | 窗口客户区 rect | 元素本地 rect | 反向 |
| `XDraw_ConvRect(hDraw, &rc)` | 元素本地 (0,0,W,H) | 画布坐标 | **GDI / GDI+ paint 必用**: hdc origin 在 resize 瞬间 / 最小化还原后状态不一致, 用 `ConvRect` 永远对 (D2D 整个窗口 RT 无偏移, 不需要) |
| `XDraw_ConvXY(hDraw, &x, &y)` | 元素本地点 | 画布坐标点 | `ConvRect` 的点版 |
| `XDraw_GetOffset(hDraw, &pt)` | — | 画布偏移 (物理) | GDI 模式直接拿 hdc origin, 已知缺陷在 resize 瞬间不准, 优先 `XDraw_ConvRect` |
| `XDraw_SetLineWidthF(hDraw, w)` | 浮点宽 | — | **D2D 路径 stroke 宽不随 transform 缩放**, 必须手动 `w * dpiScale` 物理化再传; GDI+ 同样 |

### 3.5.3 paint 时坐标系决策树

```text
拿到 hDraw
  │
  ├── XDraw_GetD2dRenderTarget(hDraw) 非 NULL?
  │     │
  │     ├── 是 (D2D 主路径)
  │     │     ├── XEle_GetWndClientRectDPI(m_hEle, &rc)  → 直接物理, 与 RT 同坐标系
  │     │     ├── stroke / pen 宽: 手动 × dpiScale + round 到整像素
  │     │     └── 圆角 / 字号: 用户给逻辑值, 这里物理化再传
  │     │
  │     └── 否 (GDI / GDI+ 兜底)
  │           ├── XDraw_ConvRect(hDraw, &rect) 转 (0,0,W,H) → 画布坐标
  │           │   (W = XEle_GetWidth * dpiScale, H 同理)
  │           ├── COLORREF 必须 & 0x00FFFFFF (alpha 高字节给 GDI 会废 brush)
  │           └── 离屏 DIB + 一次 BitBlt 上屏 (避免多次直绘 hdc 中间态闪烁)
  │
  └── *pbHandled = TRUE
```

### 3.5.4 Win32 消息边界 (物理 / 逻辑混用最容易翻车)

| 消息 | 关键参数单位 | 与本模块状态比对前需要 |
|---|---|---|
| `WM_NCHITTEST` | lParam = 物理屏幕 XY | 模块内若存 *逻辑* margin/padding, 先 `× dpiScale` 物理化, 再与 `screenX - wr.left` 比 |
| `WM_GETMINMAXINFO` | `ptMinTrackSize` 是**物理** | 模块内若存逻辑 padding 要加到最小尺寸, 先 `× dpiScale` |
| `WM_SIZE` | wParam = SIZE_*, lParam = (cy<<16)\|cx **物理** | XCGUI `XWnd_GetClientRect` 是逻辑, 两个单位别混 |
| `WM_DPICHANGED` | wParam HIWORD = 新 DPI | XCGUI 有时不派给我们 hook, **同时** 在 `WM_SIZE` 兜底重读 `XWnd_GetDPI` |
| `WM_WINDOWPOSCHANGING/ED` | `WINDOWPOS::cx/cy/x/y` 物理 | 同上 |
| `GetWindowRect / GetClientRect` (Win32) | 物理 | 同上 |

### 3.5.5 常翻车规则 (按高频排序)

1. **同一变量只存一种单位**. 用户配置入 *逻辑* 像素, 内部成员全存逻辑. **仅在 3 个地方临时 × dpiScale 物理化**:
   - DIB 内存分配 (alpha 缓冲必须按物理像素分配)
   - 与 Win32 物理坐标比对 (`NCHITTEST` / `GETMINMAXINFO` / `GetWindowRect`)
   - D2D / GDI+ stroke 宽 (stroke 不随 transform 缩放, 必须手动物理化)

2. **不要用 `(int)(x * dpiScale)`**. 截断而非 round → 视觉差 1 物理像素. 封 helper:
   ```cpp
   auto rp = [](double v){ return v >= 0 ? (int)(v + 0.5) : -(int)(-v + 0.5); };
   ```

3. **D2D / GDI+ stroke 宽必须 round 到整数物理像素**. `1.5f` 实测 → 渲成 2 px AA 边缘半透, 视觉成 "还是 1 px". 正确:
   ```cpp
   float bwPhys = std::floor(bwLog * dpiScale + 0.5f);
   if (bwPhys < 1.0f) bwPhys = 1.0f;
   XDraw_SetLineWidthF(hDraw, bwPhys);
   ```

4. **GDI 模式画布偏移 / 原点状态**: `hdc origin` 在 resize 瞬间 / 最小化还原后状态不一致, 不要假设 `(0,0)` = 元素左上角. 用 `XDraw_ConvRect(hDraw, &rect)` 一步把元素本地 (0,0,W,H) 转画布坐标, 永远对.

5. **`XEle_GetWndClientRectDPI` 的名字里有 `DPI` 但语义是 "返物理"**, 与直觉相反. 平行的 `XEle_GetWndClientRect` 是 "返逻辑". 选错就差一个 dpiScale 因子.

6. **`XDraw_ImageEx(hDraw, hImg, x, y, w, h)` 的 w/h 是逻辑**. XCGUI 内部会再 × dpiScale 渲到物理. 想 1:1 像素映射时: image 像素数按物理分配, ImageEx 传逻辑目标尺寸, 内部缩到物理 = image 实际像素. 用无尺寸版 `XDraw_Image` 在 DPI ≠ 100% 时图就被拉大 dpiScale 倍.

7. **运行期 DPI 切换 (`WM_DPICHANGED`) XCGUI 可能 swallow**. 每帧 paint 开头加一行 `int dpi = XWnd_GetDPI(hWnd); if (dpi != m_dpi) { m_dpi = dpi; m_dpiScale = dpi/96.0f; /* 重算几何 */ }`. 单次调用 ~0.1us 可忽略.

8. **`XC_EnableDPI(FALSE)` 启动的 app, `XWnd_GetDPI` 永远返 96**. 模块代码不能假设当前 dpiScale 一定 = 系统 DPI, 永远走 `XWnd_GetDPI` 拿当前值, 不要 cache "进程启动期 DPI".

### 3.5.6 模块内部存储与转换的标准范式

```cpp
class CXMyModule {
    // 全部存逻辑像素 (与用户输入同单位):
    std::atomic<int>   m_corner   {8};
    std::atomic<float> m_borderW  {1.0f};
    std::atomic<int>   m_blur     {16};
    int   m_padL = 0, m_padT = 0, m_padR = 0, m_padB = 0;
    int   m_dpi      = 96;
    float m_dpiScale = 1.0f;

    void RefreshDpi() {
        int dpi = XWnd_GetDPI(m_hWnd);
        if (dpi <= 0) dpi = 96;
        if (dpi != m_dpi) { m_dpi = dpi; m_dpiScale = dpi / 96.0f; }
    }

    // 仅在与物理边界交互时转换:
    void OnRenderBitmap() {
        RefreshDpi();
        int cornerPhys = (int)(m_corner.load() * m_dpiScale + 0.5);
        int blurPhys   = (int)(m_blur.load()   * m_dpiScale + 0.5);
        // ... 用物理值分配 DIB / 渲染
    }
    void OnPaint(HDRAW hDraw) {
        RefreshDpi();
        float bwPhys = std::floor(m_borderW.load() * m_dpiScale + 0.5f);
        if (bwPhys < 1.0f) bwPhys = 1.0f;
        XDraw_SetLineWidthF(hDraw, bwPhys);
        // 圆角 / 矩形几何用逻辑值传 XDraw_*Round* (XCGUI 内部物理化)
        XDraw_DrawRoundRectEx(hDraw, &rcLog, m_corner, m_corner, m_corner, m_corner);
    }
    LRESULT OnNcHitTest(int screenX, int screenY) {
        RECT wr; ::GetWindowRect(m_hMainHwnd, &wr);     // 物理
        int x = screenX - wr.left, y = screenY - wr.top;
        // 与逻辑 padding 比对前先物理化:
        int padLPhys = (int)(m_padL * m_dpiScale + 0.5);
        // ...
    }
};
```

```cpp
    XEle_RegEventCPP1(m_hEle, XE_PAINT_END, &CX<功能>::OnPaintImpl,   this);
    XEle_RegEventCPP1(m_hEle, XE_SIZE,      &CX<功能>::OnSizeImpl,    this);

    XEle_RegEventCPP1(m_hEle, XE_XC_TIMER,  &CX<功能>::OnTimerImpl,   this);

//============================================================================
// XE_PAINT 分流: D2D 主路径 / GDI 兜底
//============================================================================

    if (!pbHandled) return 0;
    *pbHandled = TRUE;

    ID2D1RenderTarget* rt = XDraw_GetD2dRenderTarget(hDraw);
    if (rt) {
```

### 4.1 D2D / GDI 分流 (固定模式)

```cpp
void CX<功能>::OnPaintD2D(ID2D1RenderTarget* rt, HDRAW hDraw) {
    RECT rcEle;
    XEle_GetWndClientRectDPI(m_hEle, &rcEle);   // 物理像素, 与 RT 同坐标系
    // ... 在 rcEle 内画
}

void CX<功能>::OnPaintGdi(HDC hdc, HDRAW hDraw) {
    int w = XEle_GetWidth(m_hEle);
    int h = XEle_GetHeight(m_hEle);
    int W = (int)(w * m_dpiScale);   // 逻辑像素 -> 物理像素
    int H = (int)(h * m_dpiScale);
    POINT off; XDraw_GetOffset(hDraw, &off);
    RECT rc = { off.x, off.y, off.x + W, off.y + H };

    // ⚠️ XCGUI RGBA(r,g,b,a) 布局 0xAABBGGRR, alpha 在高字节.
    //    GDI CreateSolidBrush 拒绝 alpha != 0 (按 PALETTERGB 处理) → 画笔为 NULL.
    //    所有传给 GDI 的 COLORREF 必须先 & 0x00FFFFFF.
    COLORREF gdiBg = m_xcguiColor & 0x00FFFFFF;

    // ⚠️ 离屏 DIB + 一次 BitBlt 上屏, 避免多次 GDI 直绘 hdc 出现中间态闪烁.
    //    见 video / image 模块 OnPaintGdi 实现.
}
```

### 4.2 关键不变量 (违反就是 bug)

1. **`d2d1.h` 必须先于 `module_xcgui.h`**, 否则 `POINTF` 在 `xcgui` 与 `d2d1` 中重定义冲突.
2. **`extern "C"`** 只能裹纯 C 库 (FFmpeg / OpenSSL). DirectWrite / GDI+ / D2D 是 C++ COM, 不要裹.
3. **`@依赖` 不会自动注入 #include**, 必须显式再 #include 一次. 否则 IDE 智能感知能用但 cl.exe 编译挂.
4. **公开 API 不能 break**. 已有 `Set/Get/Is/Add/Del` 的命名风格不能换. 新增能力优先 *扩展* 而非替换.
5. **GDI `COLORREF` 必须去高位**: `color & 0x00FFFFFF` 才能给 `CreateSolidBrush` / `SetTextColor` 等用.
6. **canvas 偏移**: GDI 模式 hdc origin 在 resize 瞬间 / 最小化还原后状态不一致, 用 `XDraw_ConvRect(hDraw, &rect)`
   把元素客户区坐标 (0,0,W,H) 转画布坐标; D2D 不需要 (整个窗口无偏移).

## 6. 事件系统

### 6.1 通用 XCGUI 事件 (走 `XEle_RegEventCPP1`)

适用所有元素都可能用的事件: `XE_PAINT` / `XE_PAINT_END` / `XE_SIZE` / `XE_DESTROY`
/ `XE_XC_TIMER` / `XE_LBUTTONDOWN` / 等等. 在 `InstallEvents()` 里挂. 详见
`xcgui/controls/XEventPrototypes.h` 中各事件的回调原型签名.

### 6.2 模块业务事件 (C 风格函数指针 + void* 用户数据)

模块自身才有的事件 (打开成功 / 加载完成 / 播放结束 / 帧切换), **不要** 用
`std::function` (炫语言 / C / 旧 C++ 端无法传 lambda). **不要** 试图扩展
XCGUI `XE_*` ID (那是固定枚举, 不可扩).

模板:

```cpp
// 头文件:
class CX<功能>;
//@别名  <功能>回调_<动作>
typedef void (*X<功能大写>_PROC_<动作>)(CX<功能>* pSelf, /*payload...*/ void* pUser);

class CX<功能> : public CXEle {
public:
//@备注 注册"<动作>"回调. UI 线程触发. cb=NULL 取消.
//@参数 cb 回调函数指针
//@参数 pUser 用户数据 (回调时原样回传)
//@别名  注册事件_<动作>()
    void On<动作>Event(X<功能大写>_PROC_<动作> cb, void* pUser = NULL);
private:
    X<功能大写>_PROC_<动作> m_cb<动作> = NULL;
    void*                    m_user<动作> = NULL;
};

// cpp:
void CX<功能>::On<动作>Event(X<功能大写>_PROC_<动作> cb, void* pUser) {
    m_cb<动作>   = cb;
    m_user<动作> = pUser;
}
```

### 6.3 Worker 线程 → UI 线程派发

worker 线程 *绝不* 直接调用用户回调. 通过 `std::atomic<bool> m_pending<动作>` 标志,
UI 线程在 16ms 定时器里轮询并触发:

```cpp
// worker 线程 (decoder / network / file io):
m_pending<动作>.store(true);

// UI 线程 OnTimerImpl 里:
void CX<功能>::DispatchPendingCallbacks() {
    if (m_pendingError.exchange(false)) {
        if (m_cbError) m_cbError(this, m_pendingErrCode, m_pendingErrMsg.c_str(), m_userError);
    }
    // ...
}
```

避免 `std::function` 跨线程 + 用户在回调里拿 XCGUI 锁导致死锁.

### 6.4 事件命名 (出自 `.cursor/rules/xcgui-events.mdc`)

- 控件名 + 动作: `OnVideoOpened`, `OnImageLoaded`, `OnEditChange`
- 通用: `OnPaint`, `OnSize`, `OnShow`, `OnDestroy`, `OnMouseMove`, `OnLButtonDown`
- 模板事件加 `Temp` 前缀; 扩展绘制加 `Ex` 后缀

## 7. 渲染 / DPI / BkInfo

### 7.1 D2D vs GDI 分流 (固定 if-else)

```cpp
ID2D1RenderTarget* rt = XDraw_GetD2dRenderTarget(hDraw);
if (rt)        OnPaintD2D(rt, hDraw);     // XInitXCGUI(TRUE)
else           OnPaintGdi(XDraw_GetHDC(hDraw), hDraw);  // XInitXCGUI(FALSE)
```

D2D 路径 *主要* 兼容 Win10+; GDI 路径 *兜底* Win7 SP1 / VMware 默认无 GPU 场景. **两个路径都要实现**, 不要只写 D2D.

### 7.2 DPI 标准模式

```cpp
void CX<功能>::RefreshDpiScale() {
    int dpi = XEle_GetDPI(m_hEle);
    m_dpiScale = dpi / 96.0f;
}
// OnSizeImpl 末尾调一次, 还有 XE_XC_DPI_CHANGE 处也调.
```

| 路径 | 坐标系 |
|---|---|
| D2D | `XEle_GetWndClientRectDPI(hEle, &rect)` 直接拿物理像素矩形, 与 RT 同系, **不再乘 dpiScale** |
| GDI | `XEle_GetWidth/Height` 拿逻辑像素, **乘 m_dpiScale**, 加 `XDraw_GetOffset` 偏移; 或 `XDraw_ConvRect(hDraw, &rect)` 一步转换 |

### 7.3 BkInfo 协同

## 8. 多线程模式 (大模块必备)

### 8.1 线程角色 (照搬 video 模块)

| 线程 | 工作 | 与 UI 通信 |
|---|---|---|
| **UI** (XCGUI 主线程) | 唯一可调 XCGUI API 的线程; `XE_XC_TIMER 16ms` 调度 | 直接调 |
| **m_thOpen** | 异步 IO 初始化 (avformat_open_input / 网络握手 / 大文件读) | atomic flag |
| **m_thDecode** | 解码 / 计算 (CPU 密集) | bounded queue + atomic flag |
| **m_thRender / m_thAudio** | 设备 IO (WASAPI 写) | 同上 |

### 8.2 BoundedQueue 模式 (有界 MPMC)

照搬 `_XVideo_BoundedQueue<T>` 模板. 关键点:

- `Push`: 队列满 → 阻塞等 (生产者背压)
- `PushTimeout(t, ms)`: 队列满 ms 内不空 → 返 false **丢这一条**. 防 "UI 卡 → frameQ 满 → decode 阻塞 → pktQ 满 → demux 阻塞 → audio pktQ 不喂 → audio render 静音" 链锁卡死.
- `Close`: 退出协议第一步; 关闭后 Push 返 false, Pop 把残量消费完返 false.

正常播放 UI 16ms 消费一帧, 100ms 内永远不超时, 永不丢帧; 仅 UI 真卡 100ms+ 才超时丢已解码 BGRA. **不要** 用 `skip_frame=NONKEY` 跳非 keyframe (破坏 GOP 参考链).

### 8.3 退出协议 (析构函数顺序)

```cpp
~CX<功能>() {
    m_quit = true;
    m_videoPktQ.Close(); m_audioPktQ.Close();
    m_videoFrameQ.Close(); m_audioFrameQ.Close();
    if (m_thOpen.joinable())    m_thOpen.join();
    if (m_thDemux.joinable())   m_thDemux.join();
    if (m_thVDecode.joinable()) m_thVDecode.join();
    // ... join 顺序: 数据生产者 → 数据消费者
    // 释放 FFmpeg / WASAPI / D2D / GDI 资源
}
```

## 11. 已知陷阱与避坑清单 (从既有模块血泪积累)

### 11.1 头文件与编译

| 坑 | 现象 | 解 |
|---|---|---|
| `POINTF` 重定义 | `error C2371: 'POINTF' redefinition` | `d2d1.h` 必须先于 `module_xcgui.h` |
| `extern "C"` 包错 | `error C2732: 链接规范与 ... 早期规范冲突` | DirectWrite / D2D 不要裹 extern "C" |
| `@依赖` 未注入 | 智能感知能用, 编译报缺符号 | 每个 @依赖 都要再 `#include` 真链一次 |
| `@别名 ()` 漏括号 | 炫语言端调用名不正确 | 函数 @别名 必须保留 `()`, 例 `//@别名  创建()` |

### 11.2 GDI 颜色 / 透明

| 坑 | 现象 | 解 |
|---|---|---|
| `CreateSolidBrush(0xFF000000)` 返 NULL | FillRect 不擦背景 | `color & 0x00FFFFFF` 去掉 alpha 高字节 |
| GDI 模式 hdc origin 不对 | resize / 最小化还原后画偏 | 用 `XDraw_ConvRect(hDraw, &rect)` 转坐标 |
| 多次 GDI 直绘 hdc 闪烁 | 鼠标移动抽搐 | 离屏 DIB (`CreateDIBSection`) 完成绘制, 一次 `BitBlt` 上屏 |

### 11.3 别名冲突

| 坑 | 现象 | 解 |
|---|---|---|
| `//@别名 取状态` 与父类冲突 | 炫语言端调用不到 | 改用 `//@别名 取播放状态` 等带语义前缀的名 |
| `//@别名 取位置` 与 `CXEle::GetPos` 冲突 | 同上 | `//@别名 取播放位置` |

### 11.4 多线程

| 坑 | 现象 | 解 |
|---|---|---|
| `Push` 阻塞死锁 | UI 卡 → 整条音视频管线静音 | 改用 `PushTimeout(t, 100)` |
| 解码线程直接调用户回调 | 死锁 / 跨线程访问 XCGUI | 设 `std::atomic<bool> m_pending`, UI 线程 timer 派发 |
| `OnSize` 调 `XWnd_Redraw(hWnd)` | 高频 OnSize 时 UI 吃 CPU 卡死 | 只调 `XEle_Redraw(m_hEle)`, 局部重绘 |
| `skip_frame=NONKEY` 跳非 keyframe | 画面模糊 / 预测错误 | **永远不要这样**. 改用队列 PushTimeout 丢已解码 BGRA |

### 11.5 资源 / 生命周期

| 坑 | 现象 | 解 |
|---|---|---|
| 析构里没 join 线程 | 进程退出时崩溃 / 句柄泄露 | 析构里先 `Close()` 队列, 再 `join()` 所有线程, 最后释放 FFmpeg / D2D 资源 |
| `XEle_DestroyEle` 重复调 | XCGUI 内部断言 | m_hEle 由 OnDestroy 回调时 XCGUI 自身释放, 析构里**不要**再调 |
| Direct2D 资源 device-lost 没处理 | 显卡驱动重启 / RDP 切换后画黑 | rt `BeginDraw → EndDraw`, 拿 hr 检查 `D2DERR_RECREATE_TARGET`, 失败 → 重建 RT 与所有 device-bound 资源 |

## 12. 新模块工作流 (Step-by-Step)

> 收到"新增 module_xcgui_xxx" 任务时按此走, 不要跳步.

1. **需求确认**
   - 类名 `CX<功能>`, 中文别名, 基类选择 (CXEle / CXShape / CXScrollView)
   - 公开 API 草案 (Set / Get / Is / 加载 / 卸载 / 主功能 / 事件)
   - 第三方依赖 (FFmpeg / WIC / 系统 SDK?)
   - 兼容性目标 (最低 Win 版本, D2D + GDI 双路径?)

2. **先写头文件 `.h`**
   - 复制本文 §1 骨架, 替换 `<...>`
   - 公开 enum / struct / 回调 typedef 全部加 `//@别名` 中文名
   - 类的每个公开方法加 `//@备注 / //@参数 / //@返回 / //@别名` 4 件套
   - 私有成员放在 `//@隐藏{ ... //@隐藏}` 内
   - **不要** include 不需要的头, 不要写空 `///` 注释

3. **写 `.cpp` 实现**
   - 复制本文 §4 骨架, 实 `Create / OnPaintImpl / OnSizeImpl / OnDestroyImpl`
   - 必须实现 D2D + GDI 双路径
   - 内部 helper 用 `static inline` 或匿名命名空间

4. **链接 / 资源**
   - `@lib` + `#pragma comment(lib, ...)` 双写
   - 第三方 dll 用 `@复制文件` 拷到输出目录
   - 系统 lib 显式列, 不要靠间接依赖

5. **测试 / 构建脚本**
   - 写 `test_<功能>_main.cpp` 最小可运行示例
   - 写 `build_test_<功能>.ps1` (照搬 `build_test_blur.ps1`)
   - 跑 `--autoclose=1500` 烟雾测一下

6. **写文档**
   - `xcgui/炫彩界面库/README.md` 模块表里加一行
   - 必要时写 `CX<功能>_README.md` (大模块如 video / image 一定要)
   - 在 `.cursor/rules/` 里如有项目硬约束更新, 一并补

7. **验证**
   - `verify_compile.ps1` 过编译
   - X86 / X64 / Debug / Release 4 配置都过
   - smoke test exe 不崩, 关键 API 走通
   - `XInitXCGUI(TRUE)` (D2D) 与 `XInitXCGUI(FALSE)` (GDI) 都试一遍

## 13. 项目硬约束 (来自 `.cursor/rules/`, 必须遵守)

### 13.1 核心 (`xcgui-core.mdc`)

- 必须优先使用现有封装类完成, 禁止绕过封装写底层 C API
- 缺少能力先查 `module_xcgui.h` / `html/` 文档, 把缺能力补进封装类后继续
- 所有界面对象 *最终* 继承 `CXBase`
- 构造函数不自动创建对象, 用 `Create` 两阶段构造
- 句柄成员 `m_h<XX>` / 布尔标志 `m_b<XX>` / 公共接口大驼峰
- 函数命名: `Set` / `Get` / `Is` / `Add` / `Del` / `Ex` 后缀
- 提供 `IsValid()` 判断对象有效
- *不能* 改已有封装类的公共接口, 新增能力优先补成员函数
- 生成新类前先扫现有头文件, 避免重复定义

### 13.2 事件 (`xcgui-events.mdc`)

- 通用事件放 `CXEle`, 窗口级放 `CXWindow`, 控件专属放派生类
- 控件事件命名 = "控件名 + 动作"
- 模板事件 `Temp` 前缀, 扩展绘制 `Ex` 后缀
- 自动生成回调先查 `xcgui/controls/XEventPrototypes.h`, 不要凭经验猜参数
- 低频 / 复杂事件保留底层 `RegEvent...` 注册
- 注册示例紧跟 `Create()` / `Attach()` 之后

### 13.3 文档 (`xcgui-docs.mdc`)

- API 权威来源: `module_xcgui.h`; 说明优先级: `html/` > 头注释
- xML 生成必须查 `示例/propertyList.json` (最高优先级)
- 自定义属性名必须来自 `示例/customPropertyName_*.xml`
- 禁止编造 API / 参数 / 事件名 / 控件属性名

### 13.4 目录 (`xcgui-folder-rules.mdc`)

- `base/` 核心能力 / 全局工具 / 动画基础
- `graphics/` 绘图 / 图像 / 资源处理
- `data/` 数据适配器 (ListView / Tree / Table / Map)
- 各目录职责单一, 不混放业务逻辑

### 13.5 风格 (`xcgui-style-guide.mdc`)

- 默认深色现代风格, 圆角 `10`, 轻阴影 / 轻边框 / 卡片化
- 主背景 / 卡片 / 文字 / 悬停 / 选中 / 禁用色统一
- 按钮 / 输入框 / 列表项尺寸 / 内边距 / 行高一致

### 14.2 最小 cpp 骨架

```cpp
//============================================================================
// module_xcgui_demo.cpp - CXDemo v1.0
//============================================================================
#include "module_xcgui_demo.h"

CXDemo::CXDemo() {}
CXDemo::~CXDemo() {}

HELE CXDemo::Create(int x, int y, int cx, int cy, HXCGUI hParent) {
    m_hEle = XEle_Create(x, y, cx, cy, hParent);
    if (!m_hEle) return NULL;
    InstallEvents();
    RefreshDpiScale();
    return m_hEle;
}

int  CXDemo::GetState() const { return m_state.load(); }

void CXDemo::OnDoneEvent(XDEMO_PROC_DONE cb, void* pUser) {
    m_cbDone = cb; m_userDone = pUser;
}

void CXDemo::InstallEvents() {
    XEle_RegEventCPP1(m_hEle, XE_PAINT_END, &CXDemo::OnPaintImpl,   this);
    XEle_RegEventCPP1(m_hEle, XE_SIZE,      &CXDemo::OnSizeImpl,    this);
    XEle_RegEventCPP1(m_hEle, XE_DESTROY,   &CXDemo::OnDestroyImpl, this);
}

void CXDemo::RefreshDpiScale() {
    int dpi = XEle_GetDPI(m_hEle);
    m_dpiScale = (dpi > 0) ? (dpi / 96.0f) : 1.0f;
}

int CXDemo::OnPaintImpl(HELE, HDRAW hDraw, BOOL* pbHandled) {
    if (!pbHandled) return 0;
    *pbHandled = TRUE;
    ID2D1RenderTarget* rt = XDraw_GetD2dRenderTarget(hDraw);
    if (rt) OnPaintD2D(rt, hDraw);
    else    OnPaintGdi(XDraw_GetHDC(hDraw), hDraw);
    return 0;
}

void CXDemo::OnPaintD2D(ID2D1RenderTarget* rt, HDRAW hDraw) {
    RECT rcEle; XEle_GetWndClientRectDPI(m_hEle, &rcEle);
    D2D1_RECT_F rc = D2D1::RectF((FLOAT)rcEle.left, (FLOAT)rcEle.top,
                                  (FLOAT)rcEle.right, (FLOAT)rcEle.bottom);
    ID2D1SolidColorBrush* brush = NULL;
    rt->CreateSolidColorBrush(D2D1::ColorF(0xFF8800), &brush);
    if (brush) { rt->FillRectangle(rc, brush); brush->Release(); }
}

void CXDemo::OnPaintGdi(HDC hdc, HDRAW hDraw) {
    int w = XEle_GetWidth(m_hEle);
    int h = XEle_GetHeight(m_hEle);
    int W = (int)(w * m_dpiScale);
    int H = (int)(h * m_dpiScale);
    POINT off; XDraw_GetOffset(hDraw, &off);
    RECT rc = { off.x, off.y, off.x + W, off.y + H };
    HBRUSH hb = ::CreateSolidBrush(RGB(0xFF, 0x88, 0x00));   // 注意去 alpha
    ::FillRect(hdc, &rc, hb);
    ::DeleteObject(hb);
}

int CXDemo::OnSizeImpl(HELE, int, UINT, BOOL* pbHandled) {
    if (pbHandled) *pbHandled = FALSE;
    RefreshDpiScale();
    return 0;
}

int CXDemo::OnDestroyImpl(HELE, BOOL* pbHandled) {
    if (pbHandled) *pbHandled = FALSE;
    // 释放此处的 D2D / GDI 资源 (本骨架无)
    return 0;
}
```
